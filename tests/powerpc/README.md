# ArchC PowerPC (PPC32) Architecture Model & Verification Suite

This directory contains a complete PowerPC (PPC32 / PPC405) processor model, simulator, and automated benchmark suite.

## Features
- 32 general-purpose registers (`r0`..`r31`).
- Condition Register (`CR`), Link Register (`LR`), Count Register (`CTR`).
- Big-Endian 32-bit architecture with ELF32 and ELF64 loader support.
- Throughput: **500+ MIPS**.
