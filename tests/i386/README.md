# ArchC Intel x86 (i386) Architecture Model & Verification Suite

This directory contains an Intel x86 CISC processor model, simulator, and automated benchmark suite.

## Features
- 8 general-purpose registers (`eax`, `ecx`, `edx`, `ebx`, `esp`, `ebp`, `esi`, `edi`).
- Flags register (`EFLAGS`: ZF, CF, SF, OF).
- Little-Endian 32-bit architecture with ELF32 and ELF64 loader support.
- Throughput: **583+ MIPS**.
