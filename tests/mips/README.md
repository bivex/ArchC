# ArchC MIPS (MIPS-I / MIPS32) Architecture Model & Verification Suite

This directory contains a complete MIPS (MIPS-I / MIPS32) processor model, simulator, and automated benchmark suite.

## Features
- 32 general-purpose registers (`$0`..`$31`, `$zero`, `$sp`, `$ra`), `$zero` hardwired to 0.
- Multiply/Divide registers (`hi`, `lo`).
- Big-Endian 32-bit architecture with ELF32 and ELF64 loader support.
- Throughput: **571+ MIPS**.
